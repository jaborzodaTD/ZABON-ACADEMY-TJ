# QADAM — Personal Life OS

A mobile-first personal dashboard by JABORZODA FAYZALI.

## What it does
- Russian / Tajik language switch
- Debt payoff planner with editable debt, paid amount, monthly payment, income, and salary
- Daily checklist with custom tasks
- Private journal stored in browser local storage
- JSON export backup
- Responsive design for phone and desktop

## Open
https://jaborzodatd.github.io/ZABON-ACADEMY-TJ/qadam/

If GitHub Pages is enabled for this repository, the app is available at the URL above after the deployment finishes. No account or external service is required. Data is stored locally in the browser on the device; use Export data to make a backup.

## Notes
Debt payoff estimates assume no interest, fees, or new borrowing. Financial values are editable and should be updated to reflect the current situation.
