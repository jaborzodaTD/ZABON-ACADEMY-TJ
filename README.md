# FRONTLINE: Iron Division

Браузерная RTS-демоверсия, оригинальный проект в духе классических тактических стратегий. Не является копией World in Conflict и не использует её ассеты.

## Игровой прототип
- Тактическая карта с рекой, мостом, дорогами, зданиями и двумя секторами.
- Выбор подразделений кликом/касанием; Shift+клик добавляет отряды к выбору.
- Приказы: перемещение, атака, захват.
- Пехота, танки и БТР; здоровье, дальность, урон, автоматический бой.
- Вражеские подкрепления, захват зон, реквизиция и покупка подкреплений.
- Адаптивный интерфейс для мобильного браузера и ПК; без сборки и npm.

## Запуск
Откройте `index.html` локально либо включите GitHub Pages в Settings → Pages → Deploy from a branch → `main` → `/(root)`.
